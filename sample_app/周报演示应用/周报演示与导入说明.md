# 晶圆厂布局工作台

在 Edge 或 Chrome 中打开同目录的 **晶圆厂布局工作台.html**。应用、工厂数据、轨道、实验结果和回放都在这一个文件中，展示时可断网。压缩包请先解压。投影时点“放大视图”，按 Esc 返回。布局图下的“查看移位示例”会用橙色虚线标出一台实际移动设备的起点和终点。界面里的“使用指南”也提供了示例下载。

## 输入和输出

**场景输入**支持 XLSX、CSV 和 JSON。Excel 的“产品需求”表每行给出产品编号、路线编号和需求量（lot）。已有路线可直接引用，例如 r_1。有新路线时，在“新增路线”表按顺序填写路线编号、工序序号、工序类型、设备族编号、单批用时（分钟）。类型填 process 或 delay。加工工序要能映射到厂内设备组。CSV 对应产品需求表，接受模板中文表头或 part、route、demand_lots。

本版固定 SMAT2022 LVHM_E 的既有厂房、生产设备和运输网络，计划期 10,080 分钟，有效产能系数 0.85。工作台按实际需求值匹配，请保留基准工作簿单元格中的原始精度。导出的 fab-job-v1 JSON 包含方法和场景，可供线下程序读取或转换。

**独立布局**支持 UTF-8 CSV、JSON 设备数组和 ZIP。每行必填 equipment_name、x、y；可选 tool_group、bay、width、height、original_slot、new_slot。x、y 使用同一厂房坐标系，图中以设备中心绘制。有尺寸时画矩形，缺少尺寸时画点。ZIP 应含一份 layout.csv，可附同目录的 e3_summary.json 或 summary.json。独立布局中显示的成本来自导入文件。

**关联结果包**参见“04_启发式离线结果包.json”。schema 为 fab-result-v1，scenario 与导出任务一致，method 填 heuristic_lp 或 rl，layout 包含本厂全部生产设备的结果坐标。metrics 可填写 reference_cost、optimized_cost、elapsed_sec、lp_count、moved 等原始指标。导入后，本次打开应用期间可再次选择该场景与方法查看结果。重新打开工作台后可从文件再次导入。

## 数据出处

- 工艺路线和产品来自 SMT2020 LVHM；设备位、Bay 和有向轨道来自 SMAT2022 LVHM_E。既有路线与厂内设备组的映射沿用第六周 E0 审核结果。
- 全厂启发式 + LP 使用第七周 e3_global 的 layout.csv 和 e3_summary.json。指标沿用原实验单位。该次归档保留布局和成本汇总。
- RL 曲线来自期中汇报第 19 页，含第 0 至 295 轮的 60 个评估点。第 20 页的第 95 轮原始回放抽取了 49 帧，可播放和拖动。它记录策略放置设备的过程。
- A2 / A3 案例直接载入第六周《MILP交互展示.html》的原始机位、加工量和边界物流。设备布置回放、轨道图及物流分配分别对应不同成果。生产运行时间、排队与车辆拥堵等动态仿真指标须由运行仿真实验提供。

## 源码

源码目录包含界面、布局绘制、文件读取和打包脚本。在原课程设计目录内，可用安装了 Pillow 和 openpyxl 的 Python 执行 源码/build.py，由原始实验文件重新生成应用和示例。现场使用只需打开已生成的 HTML。
